## 一、甲方需求清单（从产品/甲方视角）

### A. 部署与性能（痛点最大）
1. **迁移到 Cloudflare**：Render 免费层 30 分钟休眠、冷启动 10s+，体验差。要求部署到 Cloudflare，全球边缘节点、无冷启动、免费额度内可长期运行。
2. **打开就要快**：首屏（HTML+CSS）直出，数据接口 P95 < 200ms——靠"定时预热 + 边缘缓存"实现，用户请求永远命中缓存，而不是现场去抓 13 个网站。
3. **新闻加载慢**：现在点击分类后要等后端实时抓取（最长 60s 超时）。 unacceptable。数据必须提前备好。
4. **保留本地 Python 版**：桌面/局域网场景继续可用，两套后端 API 完全兼容，前端一套代码。

### B. 内容丰富度
5. **新增新闻源**（≥5 个，须实测可用）：百度贴吧热议、凤凰网资讯、掘金热榜、开源中国、钛媒体；V2EX 仅云端版（本地网络不可达）。
6. **修复失效源**：知乎热榜 API 已改版（404），虎嗅槽位优化。
7. 平台总数 35 → 云端 41 / 本地 40。

### C. 界面美观（当前"不够美观"）
8. **全新视觉设计**：亮/暗双主题（跟随系统 + 手动切换记忆）、精致卡片（平台色图标块、金银铜排名徽章）、更好的排版层级与留白、shimmer 骨架屏。
9. **新增「全网热榜」聚合视图**：把微博/百度/头条/知乎/B站等实时榜单融合为一张总榜，作为默认首屏——这是聚合工具的核心价值。
10. 移动端体验优化；保留全部现有功能：搜索、收藏、历史、分享、失败折叠区、平台筛选。

### D. 可靠性
11. **抓取失败不能让用户看到空卡片**：每平台多端点回退；失败时返回上一次成功数据并明确标注"上次成功 HH:MM·数据延迟"（诚实标注，不伪造）。超过 6 小时无成功才显示"不可用"。
12. 免费额度核算：Cron 480 次/天 × ≤40 子请求 < Workers 免费限额；KV 写 < 500/天 < 1000/天限额。
13. 健康检查 `/api/health` 保留，方便监控。

### E. 交付物
14. 一键部署指南（无 Cloudflare 经验也能照做）；README 更新。

## 二、技术方案

### 为什么不能"直接"把 Flask 部署到 Cloudflare
Cloudflare Workers 是 V8 隔离件（JS/TS），不能跑 Python 进程（Python Workers 仍实验性且不支持 requests/bs4）。**方案：用原生 JS 重写后端为 Worker，API 路径与响应结构与 Flask 版逐字段兼容**，前端一套代码通吃。

### 架构（cloudflare/ 目录）
```
Cloudflare Worker（单 Worker）
├── 路由：/api/* → API；其余 → 静态资源（public/index.html，即前端 SPA）
├── Cron Trigger（每 3 分钟）：轮换刷新分组平台 → 写 KV 单键 "all"
│     ├── 每轮必刷：7 个实时热搜（微博/百度/抖音/头条/知乎/B站/腾讯）
│     └── 轮换组：其余平台分 4 组，每组约 8-10 个（每平台约 12 分钟刷新）
├── KV（CACHE）：单键存全部平台数据（读多写少，天然抗并发）
├── 内存缓存：isolate 内 60s TTL，热请求零 KV 读
├── D1（可选绑定 DB）：users/favorites/history，SQL 与 SQLite 版相同
│     └── 未绑定时 /api/auth/* 返回 501，前端优雅降级
└── 认证：HS256 JWT（Web Crypto）+ sha256(pw+secret) —— 与 Flask 版令牌互通
```

### 关键实现决策
- **HTML 解析**：Python 用 BeautifulSoup+CSS 选择器；JS 版用通用 `<a href>` 正则抽取器 + 每站点 href/长度过滤规则复刻 `_html_list` 语义（够用、零依赖）。
- **编码**：UTF-8 为主；GBK 源（直播吧）在 workerd 中尝试 `TextDecoder('gbk')`，不支持则该平台在云端标记不可用（本地 Python 版正常）。
- **失败保底（两个后端一致）**：抓取失败 → 若 ≤6h 内有成功缓存 → 返回旧数据 + `update_note="上次成功 HH:MM·数据延迟"`、`is_realtime=false`。
- **UI 单文件** `templates/index.html` 为唯一正本，构建时同步到 `cloudflare/public/index.html`（部署脚本内含一致性校验）。
- **全网热榜**：前端融合（各实时榜单按 rank 权重打分取 Top 30），零后端成本。

### 免费额度核算（Workers Free）
| 项 | 消耗 | 限额 |
|---|---|---|
| 请求 | 用户访问 + cron ≈ 1 万/天 | 100k/天 |
| 单次子请求 | cron 每轮 ≤ ~40 | 50/次 |
| KV 读 | ≈ 用户批请求数 | 100k/天 |
| KV 写 | ≈ 480/天 | 1000/天 |
| D1 | 极低（仅登录用户） | 5M 读/天 |
